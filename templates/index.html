Methodology & Design

Engineered with Scientific Integrity

Addressing fundamental challenges in energy analytics through leakage-aware machine learning.

Target-Leakage Safeguard

In empirical utility records, ElectricityBill = MonthlyHours × TariffRate exactly. Predicting bills directly using tariff as an input produces an artificial R² ≈ 1.0 by simply learning multiplication. SPARK strictly predicts MonthlyHours as the genuine machine learning problem, deriving bills downstream.

Precision ML Ensemble

Evaluated across 7 regression algorithms with 3-fold cross-validation. The Gradient Boosting Regressor emerged as the champion (MAE: 70.24, R²: 0.5569) with an unbiased, normally distributed residual profile, confirming that remaining variance reflects real-world household variation.

Actionable Rupee Savings

Rule-based advisory algorithms benchmark household runtime profiles against national consumption quartiles. Users receive customized conservation strategies with prospective rupee savings calculated using their exact municipal tariff schedule.
